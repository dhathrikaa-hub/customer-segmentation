# Customer Segmentation Analysis

## Thiranex Project

### 📌 Project Overview

This project performs customer segmentation using Python and K-Means clustering.

The objective is to divide customers into meaningful groups based on demographic and purchasing behavior. These segments can help businesses understand customer preferences and design targeted marketing strategies.

---

## 🎯 Objectives

- Analyze customer demographics and purchasing behavior
- Perform Exploratory Data Analysis (EDA)
- Preprocess and scale customer data
- Apply K-Means clustering
- Determine an appropriate number of clusters using the Elbow Method
- Evaluate clustering using Silhouette Score
- Visualize customer segments
- Generate business insights for targeted marketing

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- K-Means Clustering

---

## 📊 Features Used

The project uses the following customer features:

- Age
- Annual Income
- Spending Score
- Purchase Frequency
- Total Purchases
- Online Purchases
- Website Visits
